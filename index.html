Algorithm briefing

A policy defines which ready process runs next and whether it can be preempted.

Non-preemptive

First Come, First Served

Processes are executed in the order they arrive. Once a process gets the CPU, it runs until its CPU burst is complete.

  1. Selection: earliest arrival time.
  2. Preemption: not allowed.
  3. Waiting: a process waits until all earlier processes finish.

The formulas behind the metrics.

Turnaround time (TAT)

Total time a process spends in the system, from the moment it arrives until it completes execution.

TAT = CT − AT

Waiting time (WT)

Total time a process spends waiting in the ready queue. It does not include time spent executing on the CPU.

WT = TAT − BT

Response time (RT)

Time between a process arriving and receiving the CPU for the first time. It is useful for evaluating responsiveness.

RT = First start − AT

Model assumptions: one CPU, zero context-switch overhead, integer time units, and no I/O blocking. Lower numeric priority means higher priority. Equal scheduling keys are resolved deterministically using arrival order and input order; a running process is retained on exact preemptive ties. These assumptions keep the algorithms comparable and the calculations reproducible.
